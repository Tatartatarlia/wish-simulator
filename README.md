# 虚星临渡 · 祈愿模拟器

用 Vite、React 和 TypeScript 做的角色活动祈愿模拟器。资源无限，保底和历史记录保存在浏览器本地。

## 启动

```bash
npm install
npm run dev
```

浏览器打开 http://localhost:5173/ 。

## 抽卡

- 可以祈愿 1 次或 10 次。先播放流星，再显示结果。
- 三星是蓝色流星，四星是紫色，五星是金色。十连会按每一抽出对应颜色的流星。
- 触发捕获明光时，那颗流星是炫彩，历史记录记为「捕获明光」。抽到非 UP 五星时记为「歪」。
- 历史里的抽数从上一发五星之后重新计算，第一发从第 1 抽算起。五星记录会带上命之座，6 命封顶。已经 6 命再抽到时，额外记一枚「无主的命星」。

五星基础概率 0.600%，第 74 抽起每抽提高 6 个百分点，第 90 抽必出。非大保底时有 50% 概率是本期 UP；歪了之后下一发五星必定是 UP。连续三次都是先歪、再靠大保底才拿到 UP 时，下一发五星必定捕获明光。四星在 10 抽内必出四星或以上。

## 武器祈愿

页面上方可以在「角色祈愿」和「武器祈愿」之间切换。两边的保底、命定值和历史各自计算，互不影响。

武器池默认是「神铸赋形」：五星 UP 为苍耀、香韵奏者，四星 UP 为弥坚骨、祭礼大剑、西风长枪、流浪乐章、祭礼弓。五星基础概率 0.700%，最迟 80 抽出货；抽到五星时有 75% 是 UP。点击五星武器会先询问，确认后才定轨。定轨后，抽到的五星只要不是定轨武器，历史记为「歪」，并获得 1 点命定值；满 1 点后下一把五星必定是它。更换或取消定轨也会先询问，并清空命定值。

除这些 UP 武器外，四星角色、四星武器和三星武器与角色池是同一份名单。限定 UP 武器不会进常驻歪池。

## 删除与添加

角色池的详情里可以按名字删除角色或武器。正在作为 UP 的要先换掉。武器池的详情里可以添加武器，需要填写名称和星级，也可以按名字删除。

## 仓库

「仓库」分成角色和武器两栏。角色栏列出抽到的全部角色，并显示星级和命之座。第一次获得是 0 命，之后每重复一次加 1 命，到 6 命停止。五星超过 6 命时，仓库里的「无主的命星」数量加一。四星到 6 命后不再增加。

武器栏按精炼显示。第一把是精1，重复抽到同一把武器会提高精炼，精5封顶。超过的数量另起一把，例如 2 把苍耀显示精2，7 把苍耀显示 1 把精5 和 1 把精2。两个卡池抽到的武器都记在这里。

清空仓库里的角色时，角色祈愿的累计抽数、保底和历史会一起清掉；清空角色祈愿历史时，仓库里的角色和无主的命星也会一起清掉。武器同理：清空武器栏会清掉武器祈愿历史和命定值，清空武器祈愿历史也会清掉仓库里的武器。两边互不影响，定轨选择会保留。清空前都会先询问。

## 角色名是主键

每个五星角色名只对应一组「活动名称 · 称号 · 元素」。例如把五星 UP 改成丝柯克，就是虚星临渡 · 虚渊暗星 · 冰；改成爱可菲，就是莓色香颂 · 明绚千韵 · 冰。

每个四星角色名只对应一组「称号 · 元素」。输入已有名字时，对应字段会自动填上，并在下面给出提示。

在「详情」的「添加角色」里登记新角色。五星要填活动名称、角色名称、称号、元素；四星不用填活动名称。同一个名字不能重复。新的五星立绘可以之后再补。

常驻五星、四星和三星武器的名单在 `src/data/banner.ts`。内置的角色对应关系在 `src/data/catalog.ts`。

## 五星立绘

卡面上的五星立绘按 **UP 五星的名字** 查找。名字改成谁，就显示同名图片；没有同名图片时，只保留卡池背景。

添加或更换立绘：

1. 把原图放进 `portraits-src/`。
2. 文件名必须和角色名一致，例如 `丝柯克.png`、`爱可菲.png`。
3. 开发服务器会自动压成 `public/portraits/角色名.webp`。也可以手动执行 `npm run portraits`。

压缩后宽不超过 1280、高不超过 860，并转成 webp。比这个更小的图不会被放大。
